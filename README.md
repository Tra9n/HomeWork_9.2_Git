# Financial Analytics Service

Анализатор финансовых транзакций: загружает данные из Excel-файла, фильтрует и группирует операции, строит отчёты.

## Возможности

1. ### Веб-страницы
    #### 1.1 Главная

- Принимает дату и время в формате YYYY-MM-DD HH:MM:SS и возвращает JSON с полной финансовой сводкой:
  Приветствие - "Доброе утро", "Добрый день", "Добрый вечер" или "Доброй ночи" в зависимости от времени
  Информация по картам: Последние 4 цифры карты Общая сумма расходов Кешбэк (1 рубль на каждые 100 рублей расходов)
  Топ-5 транзакций по сумме платежа Курсы валют (актуальные курсы валют) Стоимость акций из S&P500.

2. ### Сервисы
    #### 2.1 Выгодные категории повышенного кешбэка
- Анализирует, какие категории трат были бы наиболее выгодными для выбора в качестве категорий повышенного кешбэка:
Входные параметры: data - данные с транзакциями year - год для анализа month - месяц для анализа 
Выходные данные: JSON с анализом потенциального кешбэка по каждой категории

3. ###  Отчеты
    #### Траты по категории 
-Возвращает траты по заданной категории за последние три месяца: Входные параметры: data - датафрейм с транзакциями
category - название категории для анализа date (опционально) - дата, от которой отсчитываются три месяца 
(по умолчанию текущая дата)


- Покрытие тестами (100%)
